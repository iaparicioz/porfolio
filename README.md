# Ivonne Aparicio · Portfolio

Portfolio personal minimalista y tecnológico.

## Publicar en GitHub Pages

1. Crear repositorio en GitHub (ej: `ivonne-portfolio`)
2. Subir los 3 archivos: `index.html`, `style.css`, `main.js`
3. Ir a **Settings → Pages → Source: main branch / root**
4. Tu portfolio estará en: `https://aparicio-ivonne.github.io/ivonne-portfolio`
